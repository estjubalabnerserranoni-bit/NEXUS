# Pruebas de NEXUS

Las pruebas se ejecutan como una pequeña aplicación de consola para evitar dependencias adicionales.

Desde la raíz del repositorio:

```powershell
dotnet run --project tests/NEXUS.Tests/NEXUS.Tests.csproj --configuration Release
```

Se verifica el movimiento entre sectores, la energía insuficiente, la misión inicial, el análisis crítico, el número de misiones y la migración de guardados del prototipo anterior.
